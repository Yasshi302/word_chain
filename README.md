# ワードチェイン

8×8〜15×15の盤面で単語をつなげていき、最大4人で文字数を競う対戦ゲーム (Windowsデスクトップアプリ)。

## セットアップ

Node.js (LTS) が必要です。

```
npm install
npm start          # アプリ起動
```

オンライン対戦するには各プレーヤーのPC (最大4台) でそれぞれ起動します。オフライン対戦なら1台で2〜4人が交代でプレイできます。

### 配布用パッケージの作成

```
npm run dist   # dist/ にポータブル版 .exe (WordChain-1.5.1-portable.exe) を生成
```

生成される `.exe` にはElectronランタイムがすべて同梱されるため、
**Node.jsやPython等が入っていないPCでもそのまま実行できます**。インストール不要で、
ダブルクリックで起動する単体の実行ファイルです。

### アンインストール

`uninstall.bat` を実行すると、追加辞書・設定などのユーザーデータを削除します
(実行前に確認プロンプトが出ます)。そのあと `.exe` ファイルを手動で削除してください。

### 辞書の再生成 (任意)

同梱の `data/dictionary.txt` (約14万語) を作り直す場合:

```
curl -L -o JMdict_e.gz http://ftp.edrdg.org/pub/Nihongo/JMdict_e.gz
npm run build-dict -- JMdict_e.gz
```

## 遊び方

### オンライン対戦 (最大4人)

1. **ホスト**: 「部屋を作る」→ **名前**とパスワードを設定して部屋を作成。表示された6文字の部屋コードとパスワードを相手に伝える (最大3人まで参加可能)。
2. **ゲスト**: 「部屋に入る」→ **名前**・部屋コード・パスワードを入力して入室。
3. **ロビー**: 参加者が揃ったら、ホストが**盤面サイズ (8×8〜15×15)・入力時間 (10秒/30秒/1分/3分/5分/無制限)・初期文字の配置・お邪魔マスの有無と数を決めて**「ゲーム開始」。
4. **設定確認**: 各ゲストに設定内容の確認ポップアップが表示され、全員が確認するとゲームが始まる。
5. 初期文字が配置され (配置場所・数は設定次第)、先手はランダム、以降は参加順で巡回する。

名前は入力欄に一度入力すると、アプリを終了するまで次回の部屋作成・入室でも保持される。

ホストがゲーム進行の権威となり (host-authoritative)、状態を各ゲストへ配信するスター型P2P構成。

### フレンド機能 (対戦相手をワンクリックで招待)

- ホーム画面の「フレンド」から、自分専用の恒久的な**フレンドコード**(部屋コードとは別物、変わらない)を確認できる。これを対戦相手に伝え、お互いに相手のコード+ニックネームを登録し合うと**相互フレンド**になる。
- 一度対戦した相手なら、対戦結果画面に表示される「フレンドに登録」ボタンからも簡単に登録できる(コードのやり取りは対戦中に自動で行われる)。
- 相互フレンドになると、部屋を作成したホストはロビー画面の「フレンドを招待」からフレンドを選んで「招待」ボタンを押すだけで、相手のアプリに対戦招待の通知(参加ボタン付き)を直接届けられる。
- 招待は、アプリ起動中は常時維持される専用の接続(対戦データとは別回線)を通じて届く。**相手のアプリが起動していない場合は招待が届かない**(オフライン時はその場で「コードを直接伝えてください」という案内になる)。
- 招待を受け取れるのは相互登録済みのフレンドだけで、見知らぬ相手からの招待は自動的に無視される。

### オフライン対戦 (2〜4人・CPU対戦可)

「オフライン対戦 (交代プレイ)」から、対戦相手 (人間 or CPU)・人数 (2〜4人)・盤面サイズ・入力時間・初期文字の配置・お邪魔マスの有無と数を選び、1台のPCで対戦できる。通信は使わない。

- **対戦相手を「CPU」にすると**、プレーヤー1 (自分) 以外の全員がCPUになる。CPUの強さは共通で1つ選ぶ (弱い/普通/強い/最強)。
- CPUは同梱の辞書に実在する単語だけを使う (未登録語の承認をCPUに求めることはない)。

### CPUの強さ (4段階)

CPUは「今の盤面に置ける、辞書に実在する単語」をすべて洗い出したうえで、強さに応じて選ぶ長さの傾向を変える。

| 強さ | 通常時に選ぶ長さ | 特殊な確率 |
| --- | --- | --- |
| 弱い | 2〜5マス | 10%で6マス、1%で7マスを選ぶ |
| 普通 | 3〜5マス | 20%で6〜8マス、1%で置ける中で最長の単語を選ぶ |
| 強い | 5〜7マス | 10%で置ける中で最長の単語を選ぶ |
| 最強 | 常に、置ける中で最長の単語を選ぶ | 同じ長さの候補が複数あるときは、その単語の最後の文字が(辞書内で)続く単語が少ない文字を優先する (相手の次の選択肢を狭める) |

該当する長さの単語が盤面に無い場合は、置ける単語の中からランダムに選ぶ (パスは、辞書語による手が1つも置けないときのみ)。

### 初期文字の配置・お邪魔マス (ゲーム開始前の設定)

- **初期文字の配置**: 「デフォルト (中央)」は盤面中央にまとまって配置、「ランダム」は盤面内のランダムな位置に散らばって配置される。デフォルト配置かつ盤面サイズが奇数の場合は、真の中央マスから時計回り (北→北東→東→…) に配置される (偶数盤面は従来通り中央2×2ブロック)。
- **初期文字の数**: デフォルト配置は1マスか4マス、ランダム配置は1〜10マスから選べる。
- **お邪魔マス**: 有効にすると、盤面上にランダムな進入不可マスが配置される。数は手入力でき、上限は全マス数の**20%**。初期文字のマスとその**周囲2マス以内**には配置されない。単語はお邪魔マスを飛び越えて置けず、そのマスの手前で止まる。盤面上ではヒビの入ったガラスのようなテクスチャで表示される。
- **お邪魔マスの移動**: お邪魔マス配置時に有効にできる追加オプション。盤面の**未入力マスが全マス数の半分になるまで**、毎ターン**お邪魔マスのうち1マスだけ**がランダムな未入力マス (初期文字マスの周囲2マス以内、および現在の起点マス(直前の単語の末尾)の周囲1マス以内を除く) へ再配置される。半分を切ったらそれ以降は移動を止めて固定される。
- **入力時間**: 10秒/30秒/1分/2分/3分/4分/5分/無制限から選べる。無制限を選ぶと時間切れによる自動パスは発生しない。
- **対戦モード**: 「通常モード」(得点は置いた文字数の合計) と「陣取りモード」(他プレーヤーが既に所有しているマスを通ると、そのプレーヤーの得点を1点減らして所有権を奪う。奪ったマスは奪ったプレーヤーの色に塗り替わり、単語の履歴にも「(相手の名前)さん: -1点」のように被害者の減点が表示される) から選べる。
- **ボーナスマス**: 有効にすると、**得点が最下位(同点含む)のプレーヤーの手番**で、リーダーとの得点差が**10点以上**あるときだけ、差が大きいほど高確率で出現する (ゲーム開始から5ターン目までは出現しない)。10〜19点差では**加点マス(+1〜+5点)**のみ、20〜29点差ではそれに加えて**倍率マス(×2)**も、30点差以上ではさらに**倍率マスが×2〜×3のランダム**にもなる(点差が大きいほど出現候補が増える)。加点マスと倍率マスは別々の未入力マスに(重複しないよう)独立して出現することがあり、**盤面上には表示されずプレーヤーからは見えない**。両方を同時に取得した場合は、加点を適用したあとに倍率をかける (例: 3文字+加点2→倍率2で(3+2)×2=10点)。取得した瞬間だけそのマスが短く光り、「ボーナスゲット！+◯ ×◯」の表示とともに専用の効果音が鳴る (対戦モードとは独立して設定できる)。
- **アイテム**: 有効にすると、「クリア」(既存のお邪魔マスを1つ選んで解除)・「ブロック」(未入力マスに新しくお邪魔マスを1つ配置。初期文字マスの周囲2マス以内には置けない)・「ワイルドカード」(単語の経路上にある既存の文字を1つ選び、任意の文字に書き換えて確定できる)の3種類が使える。試合開始前に、それぞれ盤面に配置する数(0〜9個)を個別に設定する。各アイテムは**盤面上の非表示のマスに配置され、そのマスに新しく文字を置くと入手する**(誰も最初から所持していない)。入手した瞬間は画面中心に「アイテムGET！(アイテム名)」と表示され、専用の効果音が鳴る。
  - 「クリア」: 自分の手番中いつでも使用を開始できる。開始した時点で所持数を1消費し、画面上部に表示される**5秒のカウントダウン**の間に対象のお邪魔マスを選べれば解除される(選べなくても所持数は戻らない)。
  - 「ブロック」: 使うタイミングは選べない。**相手ターンの開始時に時計が止まり**、「ブロックを使いますか?」と確認される。使わなければ所持数は減らず、次に自分の相手のターンが来たときにまた確認される。使う場合は未入力マスを1つ選んで配置する。
  - 「ワイルドカード」: 単語入力画面で、経路上の(通常は完全一致が必要な)既存の文字から書き換えたい位置を選び、その位置には好きな文字を入力できる。単語を確定すると、盤面のその文字も実際に書き換わる(陣取りモードでは通常の上書きと同様、元の所有者の得点も1点減る)。

### 協力モード (CPU 1体 vs プレーヤー全員)

- オフライン・オンラインどちらでも、「協力モードを有効にする」にチェックすると、参加者全員 (人間) が1体のCPUを相手に協力して対戦する。CPU用の1枠を確保するため、人間の参加者は最大3人まで。
- 勝敗は個人ではなく**チーム(人間側)の合計得点 と CPUの得点 の比較**で決まる。チーム合計がCPUを上回れば「チームの勝利」、下回れば「CPUの勝利」、同点は引き分け。結果画面にはチーム合計・CPUの得点が個人成績とは別に表示される。
- このモードのCPUは、既存の強さ別CPU(弱い/普通/強い/最強)とは別の専用ロジックで手を選ぶ。単に一番長い単語を選ぶのではなく、「自分の得点(文字数)を伸ばす」ことと「単語の終端をチームが続けにくい文字にする」ことを天秤にかけ、続けにくさが十分大きければあえて短い単語を選ぶこともある。
- 協力モードのCPUも「弱い/普通/強い/最強」の4段階から強さを選べる(通常のCPU対戦とは別の選択欄)。弱いほど単語の長さだけで手を選び(チームを妨害する意図が弱い)、強いほど「チームが続けにくい終端の文字」を重視して手を選ぶようになる。

### 途中退出・切断

- ゲームの途中でプレーヤーが切断された場合、ホストは「**プレーヤーを待つ**」「**残りで継続する**」「**ゲームを終了する**」から選べる。
- 「待つ」を選ぶと、切断したプレーヤーが同じ部屋に入り直して復帰できる (状態を再同期)。切断後に部屋コードを忘れても入り直せるよう、**対戦画面にも部屋コードを常時表示**している。
- 参加者が1人になった場合はゲーム終了。

### 画面表示・演出

- 背景は**星座をイメージした星空アニメーション** (星がまたたき、近い星同士が線でつながる。まれに流れ星)。
- 単語を盤面に置くとき、**先頭の文字から1つずつ拡大→縮小して置かれる**演出が入る。
- 最後に置かれた単語の上には線が描画される (起点が●、終点が矢印)。色は置いたプレーヤーの色 (最大4色)。
- 各プレーヤーの得点と現在の手番が常に表示される。
- 対戦成績 (勝ち/負け/引き分け) はアプリを終了するまで保持され、ホーム画面・ゲーム画面・結果画面に表示される。

### チャット (オンライン対戦)

- ゲーム画面右下の**吹き出しマーク**を押すとチャットが開く。未登録単語の承認理由の説明などに使える。
- メッセージを送ると、相手の画面に**ポップアップ**で表示され、チャット欄にも記録される (未読バッジ付き)。
- 通信はホスト経由でリレーされ、送信者以外の全員に届く。
- 単語の承認待ちなど画面がモーダルでロックされている間も、チャットの吹き出し・パネルは常に最前面に表示され、いつでも開いて使える。

### 音 (BGM・効果音)

- BGMは**宇宙をテーマにした静かなピアノ曲**。効果音とともに Web Audio でその場で合成しており、外部ファイルは不要 (オフラインで鳴る)。
- 効果音: 文字を置く音・単語成立・手番通知・ボタン・承認/拒否・チャット受信・勝敗 など。
- 「設定」画面で **BGMと効果音の音量**を個別に調整でき、設定は保存される。

### 再戦と退出

- オンラインの再戦は、接続中の**全員が「再戦する」を選んで同意**するとロビーに戻り、ホストが再設定して新しいゲームを始められる。
- ホストが退出した場合は、参加者全員が自動的にホームへ戻る。

### 辞書の編集 (設定画面)

- ホーム画面の「設定 (辞書の編集)」から、対戦中に承認して追加した単語を一覧・追加・削除・検索できる。
- 同梱の基本辞書 (約14万語) は変更されない。編集対象はユーザーが追加したカスタム単語のみ。
- 追加単語は `custom-words.json` に `{ updatedAt, words }` 形式で保存され、最終更新日時も記録される。

### 辞書の自動マージ (オンライン対戦時)

- オンライン接続が成立すると、双方のカスタム辞書を自動的に同期する。
- 両者の追加単語を **union (和集合) でマージ**するため、どちらの単語も失われない。
- マージ後の最終更新日時は、**新しい方 (最終更新日が新しい側)** を採用し、双方が同一の辞書に収束する。

### ルール

- 先手は初期文字のマスから1文字選び、8方向 (縦・横・斜め) のいずれかに単語を伸ばす。
- 単語はひらがな2〜15文字で、盤面やお邪魔マスからはみ出してはいけない。
- 途中にすでに文字があるマスを通る場合、その文字と一致する必要がある (例: 「あ」から「あ◯め」→「あにめ」)。「ゃ」「っ」などの拗音・促音が交点にある場合、対応する直音 (「や」「つ」など) で入力してもよい。
- 次のプレーヤーは前の単語の**末尾の文字のマス**から単語を作る (しりとり形式)。
- 単語は同梱の単語リストと照合される。リストにない単語は相手が承認すればOKとなり、以後の単語リストに追加される。拒否された場合、時間が残っていれば再入力できる。
- リストにない単語は、**他のプレーヤー全員が承認**したときのみ成立する (1人でも拒否すると不成立)。オフラインでは代表の1確認で処理する。
- 承認待ちの間、入力タイマーは停止する。
- 時間切れになるとパス。**参加者全員が連続でパスするとゲーム終了**となり、置いた単語の合計文字数が最も多いプレーヤーの勝ち (同点は引き分け)。
- 得点は単語の全文字数 (既存の文字を利用した分も含む)。陣取りモードでは、これに加えて他プレーヤーが所有するマスを通るたびそのプレーヤーの得点が1点減り、そのマスの所有権が自分に移る (誰も所有していない初期文字のマスを通っても減点はない)。ボーナスマス有効時、加点マスを通った単語は文字数に加点され、倍率マスを通った単語は(加点適用後の)得点がまるごと倍になる。

### 細則 (実装で定めた仕様)

- 「ん」で終わる単語は使えない (次のプレーヤーが続けられないため)。同様に、長音「ー」など、どの単語の先頭にもならない文字で終わる単語も不可。
- 「っ」「ゃ」「ゅ」「ょ」「ぁ」「ぃ」「ぅ」「ぇ」「ぉ」で終わる単語は、対応する直音 (「つ」「や」「ゆ」「よ」「あ」「い」「う」「え」「お」) で終わる単語として扱われる (その直音から始まる単語が辞書にあれば使える)。
- 1手につき最低1マスは新しい文字を置く必要がある (既存の文字を完全になぞるだけは不可)。
- 同じ単語は1ゲーム中1回まで。
- カタカナで入力しても自動的にひらがなに変換される。
- 単語入力欄はローマ字直接入力に対応し、アルファベットを入力すると即座にひらがなへ変換される (OSのIME変換候補には頼らない)。
- 時間切れ以外でも「パスする」ボタンで任意にパスできる。
- 置ける場所が物理的に無い場合はパスするしかない (画面に案内が出る)。
- ゲーム終了後、参加者全員が同意すると再戦できる (オンライン)。

## 自動更新

- オンライン対戦の部屋に入った時点 (ホストは部屋作成前、ゲストは入室直後) で、自分のバージョンが最新かを確認する。取得元は常に [GitHub Releases](https://github.com/Yasshi302/word_chain/releases) で、**対戦相手から直接コードを受け取って実行することは一切しない**。
- 古い場合は画面下部に「最新バージョンがあります。最新化中・・・」とプログレスバーを表示しながら、新しいポータブルexeをダウンロード → 直前のバージョンを1世代だけバックアップ → 差し替え → 再起動する。ゲストは再起動後、同じ部屋コード・パスワードで自動的に再入室する。
- ホストの「開始」ボタンは、参加者の誰かが最新化している間は無効化され、全員の最新化が完了するまで対戦は始まらない。
- 設定画面の「前のバージョンに戻す」から、直前のバージョンにいつでも手動で戻せる。
- ネットワーク障害やダウンロード失敗時は自動更新をスキップし、現在のバージョンのまま対戦を続行する (更新の失敗が対戦を妨げないようにしている)。
- 実行ファイルはコード署名していない (Windows SmartScreenの警告と同じ事情)。自動更新も「未署名のexeを未署名のまま差し替える」形になる点は既知の妥協点として明記しておく。

## 通信とセキュリティ

- **ポート開放は不要**: WebRTCのNAT越え (STUNによるホールパンチング、失敗時はTURN中継へ自動フォールバック) を使うため、ルーターのポートフォワーディング設定は要らない。ICEサーバ (Google STUN + PeerJS無料TURN) を明示指定し、CSPの `connect-src` でも `stun:`/`turn:` を許可している。ごく一部の厳格なファイアウォールやCGNAT環境では接続できないことがあるが、これはポート開放では解決しない (別ネットワークを推奨)。
- **P2P通信**: ゲーム中の通信はWebRTCデータチャネルによるホスト⇔ゲストの直接通信で、DTLSにより暗号化される。
- **シグナリング**: 接続確立時のみPeerJS公開サーバ (0.peerjs.com) を仲介に使う。確立後のゲーム内容は仲介サーバを経由しない。
- **入室認証**: パスワードはチャレンジレスポンス方式 (HMAC-SHA256) で検証し、パスワード自体は送信しない。認証失敗が続くと一定時間入室を受け付けない。
- **入力検証**: 受信メッセージはサイズ上限・型・値域 (座標0〜14、ひらがな2〜15文字など) をすべて検証してから処理。単語の表示は常にtextContent経由でXSSを防止。ホストは各ゲストの手を自分の盤面ルールで検証してから適用する (host-authoritative)。
- **切断検知**: アプリ層のハートビートで相手の生存を監視し、WebRTCが検知できない突然の切断も検出する。
- **辞書同期の検証**: 辞書同期メッセージも語数・各単語の形式・サイズ上限を検証。取り込む単語はひらがな2〜15文字のみ。
- **Electronの堅牢化**: contextIsolation / sandbox 有効、nodeIntegration 無効、CSP設定、ナビゲーション・新規ウィンドウ全面ブロック、IPC入力検証。
- **フレンド招待の信頼判定**: 招待の送信元が本当にそのフレンドコードの持ち主かどうかは、メッセージ内の自己申告フィールドではなく、**実際に接続してきたPeer ID**をフレンド一覧と照合して判定する(自己申告のみでのなりすましはできない)。フレンド以外からの接続は無条件で無視する。

### v1.5.0

### v1.4.0
- アイテムの入手方法を全面的に変更。試合開始時から所持している方式をやめ、盤面上の非表示マスにランダム配置し、そのマスに新しく文字を置いた瞬間に入手する方式にした。入手時は画面中心に「アイテムGET！(アイテム名)」と表示され、専用効果音が鳴る。
- 新アイテム「ワイルドカード」を追加。単語入力画面で、経路上の既存の文字(通常は完全一致が必要)を1つ選んで任意の文字に書き換え、確定すると盤面のその文字も実際に書き換わる。
- 「クリア」の使用方法を変更。自分の手番中に使用を開始すると、その時点で所持数を1消費し、5秒のカウントダウン(画面上部に表示、拡大→縮小の演出付き)以内に対象のお邪魔マスを選べば解除される。選べなくても所持数は戻らない。
- 「ブロック」の使用方法を変更。相手ターンの開始時に時計を止めて「使いますか?」と確認するようにした(以前の「猶予期間中いつでも使える」方式から変更)。使わない場合は所持数を消費せず、次に相手のターンが来たときにまた確認される。
- 陣取りモードで、他プレーヤーの文字を上書き(またはワイルドカードで書き換え)したとき、そのマスの色が奪ったプレーヤーの色に塗り替わるようにした(以前は色が変わらないままだった)。
- 陣取りモードの単語履歴に、マスを奪われたプレーヤーの減点を「(名前)さん: -◯点」の形で表示するようにした。

### v1.3.0
- ボーナスマスを全面的に再設計。得点差**10点以上**の最下位プレーヤーの手番にだけ、開始5ターン以降に出現するようにした(以前と同じ)。加えて、10〜19点差は加点マス(+1〜+5)のみ、20〜29点差は加点マス+倍率マス(×2)、30点差以上は倍率マスが×2〜×3にもなる、という累積型に変更。加点マスと倍率マスは別々の未入力マスに(重複しないよう)独立して出現し、**盤面上には表示されずプレーヤーからは見えない**ようにした。両方を同時に取得した場合は加点を適用したあとに倍率をかける。取得した瞬間はそのマスが短く光り、「ボーナスゲット！+◯ ×◯」の表示と専用効果音で知らせる。
- お邪魔マスの移動オプションで、1ターンに移動するマスを**1マスだけ**に変更(以前は最大5マスまで)。移動先は初期文字マスの周囲2マスに加え、**現在の起点マス(直前の単語の末尾)の周囲1マス**にも配置されないようにした。
- アイテムの使用回数を、ゲーム開始前に「クリア」「ブロック」それぞれ個別に(0〜9回)設定できるようにした(以前は各1回固定)。また「ブロック」は、自分の手番が終わったあとも**相手が次の手を確定するまで**引き続き使えるようにした(不意打ちで自分の直後を塞がれるのを防ぐ猶予期間)。
- オンライン対戦中に接続が切れた際、部屋コードが分からず入り直せなくなるのを防ぐため、**対戦画面にも部屋コードを常時表示**するようにした。
